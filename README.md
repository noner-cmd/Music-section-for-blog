
# 个人博客音乐展示模块

## 一、项目概述
通过本项目可为你的个人博客添加了“最近在听”音乐展示模块，通过获取指定歌单中的歌曲信息，在博客页面展示歌曲名称、歌手、专辑封面图片以及歌曲ID。为优化性能，减少API调用次数，程序会定期获取数据并保存到`info.json`文件，博客页面直接读取该文件展示内容。

## 二、文件结构
1. **`music.php`**：核心PHP文件，负责从音乐API获取歌单歌曲ID，再根据ID获取歌曲详细信息，将处理后的数据存入`info.json`文件，并以JSON格式输出，供前端调用。
2. **`info.json`**：存储歌曲信息的文件，由`music.php`定期更新，包含歌曲名称、图片链接、歌手和ID等信息。
3. **`example.html`**：实例博客页面文件（在完成部署并测试无误后可删除），展示`info.json`获取的“最近在听”歌曲信息。

## 三、使用方法
1. **配置API信息**：在`music.php`文件中，修改`$playlistId`为目标歌单ID，`$token`为有效的API访问令牌。
2. **运行PHP脚本**：通过服务器的任务调度工具（如Linux的Cron Job）定期执行`music.php`脚本。在Linux系统中，使用`crontab -e`命令编辑Cron表，添加一行类似于`0 * * * * /path/to/php /path/to/full.php`的任务，其中`/path/to/php`是PHP可执行文件路径，`/path/to/full.php`是`full.php`脚本的实际路径，该任务设置为每小时执行一次，可根据需求调整。
3. **部署文件**：将`music.php`、`info.json`和`example.html`上传至服务器的合适目录，确保`music.php`有执行权限，`info.json`有读写权限。

## 四、技术实现
1. **PHP部分**：利用`curl`库向音乐API发起请求，获取歌单和歌曲详情数据。通过解析JSON格式的响应数据，提取所需歌曲信息。使用`file_put_contents`函数将数据写入`info.json`文件，并通过`header`函数设置响应头，以JSON格式输出数据。
2. **HTML部分**：使用HTML和CSS构建博客页面布局，展示个人介绍、博客文章和歌曲信息。通过JavaScript的`fetch` API读取`info.json`文件内容，动态生成歌曲展示元素并添加到页面中。

## 五、注意事项
1. **API调用限制**：频繁调用音乐API可能会触发限制，合理设置任务调度时间间隔，避免过度请求。
2. **文件权限**：确保`info.json`文件具有正确的读写权限，否则`music.php`无法更新数据。
3. **API密钥安全**：妥善保管API访问令牌`$token`，避免泄露，防止恶意调用造成不必要的损失。 

## 六、测试
在完成部署后手动访问一次`music.php`，查看是否能正常输出歌曲信息和将信息写入`info.json`，再访问`example.html`查看最近在听板块是否有歌曲出现。若一切正常，则可以删除`example.html`并在你自己的博客页面中加入相关板块用于读取和显示`info.json`的内容。
